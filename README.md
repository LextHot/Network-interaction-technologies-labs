# Технологии сетевого взаимодействия - Лабораторные работы

Репозиторий содержит выполнение лабораторных работ №2 и №3 по дисциплине «Технологии сетевого взаимодействия», посвященных разработке на базе **FastAPI**, валидации данных через **Pydantic**, работе с базами данных (**SQLite** + **SQLAlchemy**) и контейнеризации с помощью **Docker**.

---

## Стек технологий

* **Язык программирования:** Python 3.11+
* **Фреймворк:** FastAPI
* **ASGI-сервер:** Uvicorn
* **Валидация данных:** Pydantic v2
* **База данных (ЛР №3):** SQLite, SQLAlchemy
* **Контейнеризация:** Docker

---

## Описание лабораторных работ

### Лабораторная работа №2: FAST API, Pydantic и Docker

* Реализация на базе FastAPI:
* `GET` — получение списка объектов и выборка по идентификатору/фильтрам.
* `POST` — создание новой сущности с автоматической генерацией ID.
* `DELETE` — удаление сущности по идентификатору.


* Валидация входных данных и строгая типизация с помощью Pydantic моделей.
* Локальное хранение данных.
* Автоматическая генерация интерактивной спецификации в Swagger UI.
* Упаковка приложения в Docker-образ с помощью `Dockerfile`.

### Лабораторная работа №3: Интеграция с СУБД (SQLite)

* pass

- Перенос хранения данных в СУБД **SQLite**.
- Взаимодействие с базой данных через **SQLAlchemy**:
- Добавление эндпоинта для частичной модификации данных `PATCH` с предварительной валидацией через схемы Pydantic.

## Установка и локальный запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/LextHot/Network-interaction-technologies-labs.git
cd Network-interaction-technologies-labs
```

### 2. Настройка виртуального окружения

```bash
# Создание виртуального окружения
python -m venv venv

# Активация окружения (Windows PowerShell):
.\venv\Scripts\Activate.ps1

# Активация окружения (Linux / macOS):
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Запуск сервера разработки

```bash
# Запуск лабораторной работы №2:
uvicorn Lab2:app --reload --host 127.0.0.1 --port 8000

# Запуск лабораторной работы №3:
uvicorn Lab3:app --reload --host 127.0.0.1 --port 8000
```

## Запуск через Docker

---

# Замечание
Для сборки контейнера ЛР№2 или ЛР№3 необходимо скопировать файл исходного кода .py, requirements.txt и Docker в корневую папку проекта из соответствующей лабе папки. Только после этого можно выполнять команды по сборке контейнера.

---

### 1. Сборка Docker-образа

```bash
# Для лабораторной работы №2:
docker build -t Lab2-app .

# Для лабораторной работы №3:
docker build -t Lab3-app .
```

### 2. Запуск контейнера

```bash
# Для лабораторной работы №2:
docker run -d -p 8000:8000 --name Lab2-container Lab2-app

# Для лабораторной работы №3:
docker run -d -p 8000:8000 --name Lab3-container Lab3-app
```

Для остановки контейнера:

```bash
# Для лабораторной работы №2:
docker stop Lab2-container
docker rm Lab2-container

# Для лабораторной работы №3:
docker stop Lab3-container
docker rm Lab3-container
```

## Примеры эндпоинтов

| Метод | Путь | Описание |
| --- | --- | --- |
| `GET` | `/Students` | Получение списка всех записей (с поддержкой фильтрации) |
| `GET` | `/Students/{id}` | Получение подробной информации по ID |
| `POST` | `/Students` | Добавление новой записи (валидация тела запроса) |
| `PATCH` | `/Students/{student_id}` | Частичное обновление данных студента (ЛР №3) |
| `DELETE` | `/Students/{id}` | Удаление записи по ID |
|  |  |  |
